01 / APPLIED ML · TEAM PROJECT

Code vulnerability detection

A web application that uses machine learning to flag potentially vulnerable C/C++ snippets and make model outputs easier to inspect.

CodeBERTscikit-learnFastAPIReactD3.js
Explore the code ↗
Inside the project +

The problem

Make vulnerability predictions accessible through a tool that accepts source code and exposes the signals behind its output.

The approach

A React interface connects to a FastAPI backend serving classical models, handcrafted security-feature variants, and CodeBERT models.

The output

Predictions, confidence where supported, extracted code metrics, classical-model comparisons, D3 dataset visualizations, and JSON export.

The boundary

This is a prediction tool. A model label alone does not establish that code is secure; results need validation and human review.

02 / TIME SERIES · TEAM PROJECT

Traffic prediction & route guidance

Connects traffic-flow forecasting to route planning: predict sensor flow, estimate travel time, and use A* search to recommend three routes across an 18-node network.

PythonXGBoostRandom ForestLSTM / GRUA* search
Explore the code ↗Read the notebooks ↗
Data, evaluation & limitations +

The data

Directional SCATS readings from October 2006, reshaped into 15-minute observations with time, sensor, lag, and rolling-flow features.

The evaluation

Training uses dates before October 25; testing uses the remaining period. Published MAE favors XGBoost among these runs. Sequence models use fewer test observations, so the evaluated samples differ.

The application

A React interface lets users select endpoints, a date, a time, and a model, then inspect three recommended routes and edge-level costs.

The limitations

Historical data, approximate straight-line edge distances, and an assumed flow-to-speed relationship limit how these results translate to live road conditions.
