# Khant Thu Aung — Portfolio

A responsive, static portfolio for GitHub Pages. No build step or dependencies required.

## Preview locally

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Customize

Edit `index.html` for biography, project descriptions, and links. Edit `styles.css` for colors and layout. Project information is based on the public GitHub profile; the project panels are typographic covers, not application screenshots. Fonts load from Google Fonts, with local sans-serif fallbacks.

## Publish

Commit and push to the branch configured in the repository's GitHub Pages settings. Serve from the repository root. This project requires no build command.
